# Contributing

Keep changes focused on scene-conditioned device-flow modeling and practical ASC
integration. For algorithm changes, identify the equation or training behavior they
affect in the pull request.

## Development

```bash
python -m pip install -e '.[dev]'
ruff check .
python -m unittest discover -s tests -v
python tools/check_repository.py
```

Keep anchor moments in float32, use one scene and device label per anchor feature,
and preserve the commit-after-optimizer lifecycle. Auxiliary-head changes should
retain gradients while fixing stochastic behavior and normalization statistics.

Do not commit audio, feature caches, training checkpoints or credentials. Add
experiment results with their configuration, dataset partition, seed and aggregation
convention. Keep new experiment outputs separate from `benchmarks/paper_*.csv`,
which records the accompanying manuscript's tables.

The SVG artwork is generated by `tools/build_assets.py`. Prefer updating the source
generator so figures remain editable and consistent.
